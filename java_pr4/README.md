## Задание 1 — Времена года (`seasons`)

| Файл | Роль |
|---|---|
| `Season.java` | `WINTER(-8)`, `SPRING(9)`, `SUMMER(24)`, `AUTUMN(7)`. Абстрактный `getDescription()` |
| `SeasonDemo.java` | Любимое время года, switch по нему, полный список |

- `SUMMER` переопределяет `getDescription()` → «Теплое время года».
- Остальные получают реализацию «Холодное время года».
